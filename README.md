# 空闲时间小工具（课表解析与空闲时段计算）

一个用 **C++17** 编写的小工具：读入课表，计算每天的空闲时段，并求多个人的共同空闲时间。
一个程序同时满足三个需求。

---

## 一、功能需求对照

| 需求 | 说明 | 对应菜单 |
| --- | --- | --- |
| 【需求1】读入课表 | 支持**手动录入**或**从 CSV 读入**；打印「本周课表」文本视图 | `1` / `2` / `4` |
| 【需求2】算空闲时段 | 给定每天可用时间范围（默认 08:00–22:00），算出空闲时段；**相邻课程自动合并，不出现碎片** | `5` |
| 【需求3】找共同空闲时间 | 输入多个人课表，算所有人共同空闲时段，**结果按长度从长到短排序** | `6` |

## 三、编译与运行

**编译：**

```bash
g++ free_time.cpp -o free_time.exe -std=c++17 -finput-charset=UTF-8 -fexec-charset=UTF-8
```

（Windows 也可直接双击 `build.bat`。）

**运行：**

```bash
free_time.exe                 # 进入交互菜单
free_time.exe 课表_张三.csv    # 也可在命令行直接读入 CSV 后再进菜单
```

> 程序在 Windows 下会自动把控制台输入/输出编码设置为 UTF-8，中文不会乱码；
> 并使用 `std::filesystem::u8path` 正确打开含中文的文件名。

## 四、CSV 文件格式

固定 5 列，表头可省略：

```
课程名,星期,开始时间,结束时间,周次
```

| 列 | 含义 | 示例 |
| --- | --- | --- |
| 课程名 | 课程名称 | `高等数学` |
| 星期 | `1`~`7`，或 `星期一`~`星期日`、`周一`~`周日` | `1` |
| 开始时间 | `HH:MM` | `08:00` |
| 结束时间 | `HH:MM` | `09:40` |
| 周次 | `1-16`，或 `1-4,6-18`；留空表示每周 | `"1-16"` |

示例文件内容：

```csv
课程名,星期,开始时间,结束时间,周次
高等数学,1,08:00,09:40,"1-16"
大学物理,1,10:00,11:40,"1-16"
大学英语,2,08:00,09:40,"1-4,6-16"
```

> **关于周次里的逗号**：`1-4,6-18` 本身含逗号，会与 CSV 分隔符冲突。
> 因此建议用双引号包起来（如 `"1-4,6-18"`）。程序对未加引号的情况也会自动把多余字段
> 拼回周次列，最大程度容错。

## 五、合并规则（消除碎片）

程序把「相邻或间隔 **≤ 10 分钟**」的课程区间合并，因此不会出现
`09:00-09:45`、`09:55-10:40` 这种被 10 分钟课间切开的碎片：

- 打印课表时，**同一门课的连续小节**会合并成一块，如 `09:00-10:40 高等数学`；
- 计算空闲时段时，被占用的时间先合并再扣除，因此空闲结果里也不会夹着 10 分钟小块。

阈值定义在源码常量 `MERGE_GAP`（单位：分钟），可按需调整。

## 六、使用示例

以 `课表_碎课示例.csv` 为例（同一门课被 10 分钟课间分成两段）：

```
课程名,星期,开始时间,结束时间,周次
高等数学,1,09:00,09:45,"1-16"
高等数学,1,09:55,10:40,"1-16"
```

**需求1（打印课表）** 输出：

```
星期一:
    09:00-10:40  高等数学      <-- 两小节已合并
```

**需求2（空闲时段，08:00–22:00）** 输出：

```
星期一（可用 08:00-22:00）: 08:00-09:00(60分钟)、10:40-14:00(200分钟)、...
                                  ^^^^^^^^^^^^^^^^^^^ 没有 09:45-09:55 的碎片
```

**需求3（多人共同空闲）** 会先加载多份课表，再对每一天求所有人空闲时段的**交集**，
最后把所有天的结果**按长度降序**输出，例如：

```
========== 所有人共同空闲时段（第 1 周，按长度降序） ==========
    星期日  08:00-22:00  (840分钟)
    星期四  15:30-22:00  (390分钟)
    ...
```

## 七、菜单一览

```
1. 手动录入课表
2. 从 CSV 读入课表
3. 载入示例课表（杨骐维/张三/李四）
4. 打印本周课表            【需求1】
5. 计算单人空闲时段        【需求2】
6. 计算多人共同空闲时段    【需求3】
7. 保存课表到 CSV
0. 退出
```

「周次」用于筛选：例如输入第 1 周，只会显示/计算第 1 周实际有课的课程。
